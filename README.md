### Usage
1. Load into **Grow A Garden 2** in Roblox
2. Configure your seeds, target pets, and gears in the application UI
3. Press your configured **Start Macro** hotkey and step away

| Default Hotkey | Action |
|--------|--------|
| `F4` | Start (Customizable in Settings) |
| `F5` | Stop (Customizable in Settings) |

### Features
* **Auto-Buy Wild Pets:** Smooth vector pathing straight to rare pet spawn coordinates.
* **Navigation Calibration:** Built-in tool in the Misc Tab to test shop tracking before fully running.
* **Discord Integration:** Send purchase updates and live screenshots directly to your webhooks.
